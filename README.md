# 🎮 Project Revival - Player Login System

Esta é a interface oficial de autenticação e cadastro de jogadores do Project Revival. 

## ⚡ Integração com o Banco de Dados
* Integrado diretamente ao Firebase Auth e Realtime Database.
* Atualiza automaticamente o estado do player para `online` ou `offline` refletindo instantaneamente no Painel Administrativo.
* Contém trava de segurança que impede logins de contas sinalizadas como banidas pelo painel mestre.
